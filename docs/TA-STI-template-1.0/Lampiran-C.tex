\chapter{HASIL EVALUASI KUANTITATIF PER \textit{FIXTURE}}

Lampiran ini menyajikan nilai metrik lengkap untuk seluruh 102 \textit{fixture} evaluasi pada sistem \textit{GraphRAG} Kubernetes. Tabel~\ref{tbl:ansq-full} menampilkan metrik \textit{Answer Quality} (AnsQ); Tabel~\ref{tbl:retq-full} menampilkan metrik \textit{Retrieval Quality} (RetQ); dan Tabel~\ref{tbl:reaq-full} menampilkan metrik \textit{Reasoning Quality} (ReaQ). Kolom \textbf{Sint.}\ dan \textbf{Skema} pada Tabel~\ref{tbl:ansq-full} hanya relevan untuk \textit{fixture} bertipe \texttt{yaml}; nilai ``---'' menunjukkan bahwa metrik tersebut tidak diukur atau tidak berlaku untuk \textit{fixture} yang bersangkutan (mis.\ \textbf{Faithfulness} pada \textit{fixture} yang gagal dinilai oleh RAGAS, atau \textbf{HopAcc} pada \textit{fixture} tanpa \textit{expected path}).

Singkatan tipe \textit{fixture}: \textit{cmd} = perintah, \textit{cncpt} = konseptual, \textit{fllwp} = lanjutan, \textit{plan} = perencanaan, \textit{rlwld} = skenario nyata, \textit{rel} = relasional, \textit{trbl} = \textit{troubleshooting}, \textit{yaml} = generasi YAML.
